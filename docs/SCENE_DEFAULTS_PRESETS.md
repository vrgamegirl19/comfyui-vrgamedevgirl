# Scene Defaults presets

Scene Defaults is a bulk editor. With no scene cards checked, edits apply immediately to all eligible scenes. With cards checked, edits apply only to those cards. The banner always identifies the scope, including real scene numbers. The result row reports the updated scope and provides **Undo** for the last edit or complete preset application.

Camera flow, camera speed, cut frequency/style, performance style, character speed, facial performance and custom facial text are stored per scene, not linked to a changing global value. A slow Rock verse can coexist with a fast Metal chorus. **Story arc detail remains project-wide**, even with scenes selected. No new Scene Settings area is added inside scene cards.

Selecting Speed or Music style applies immediately. Selecting a named Saved preset loads and applies it immediately as one operation. Opening the panel or loading the list does not apply a preset automatically. The Fill Missing, Replace All and Apply to selected buttons are removed.

## Speed

All values are on the existing 0–10 scales.

| Speed | Camera motion | Character motion | Cut frequency |
| --- | --- | --- | --- |
| Static | 0 | 0 | 0 (continuous shot) |
| Slow | 2 | 2 | 1 |
| Medium | 5 | 5 | 4 |
| Fast | 8 | 8 | 7 |

## Music style

Music style changes framing, performance and facial direction, and clears prior custom facial text. It preserves the chosen speed and cut frequency.

| Music style | Auto camera flow | Performance | Facial performance |
| --- | --- | --- | --- |
| Rock | Music video shots | Rock / punk | Rock / intense |
| Metal | Fast energetic | Metal / screaming | Metal / rage |
| Rap | Medium shots | Rap / hip-hop | Rap / high intensity |
| Soft | Medium shots | Ballad / emotional | Love song / tender |
| Pop | Music video shots | Pop performance | Pop / polished stage |

Film planning modes use their supported acting and facial presets: Rock → Punk bar attitude / Defiant controlled; Metal → Tense confrontation / Defiant controlled; Rap → Noir restraint / Defiant controlled; Soft → Emotional confession / Vulnerable confession; Pop → Dialogue naturalism / Default natural. Framing remains as above.

Applying any built-in or named preset sets **video aesthetic to Default, temporal/world effect to Off, and shot FX to Off**. These can be edited afterward. Manually editing a preset's component controls clears its toolbar selection so the label cannot imply those settings still match.

## Named presets

Enter a name and choose **Save preset**. Select it from **Saved presets** to load and apply it automatically. Existing names require confirmation before replacement; names that sanitize to the same filename cannot overwrite one another accidentally.

Snapshots include the camera flow (including a custom camera list), both motion speeds, cut frequency, performance/facial settings and custom facial text, consistency phrase, story arc detail, and Image Prep settings. The effect/aesthetic baseline above is enforced when saving and loading. Inactive custom video aesthetic and effect configuration are not part of the snapshot. Project metadata, scenes, reference assets and generated prompts are excluded.

Files are saved globally beside the existing video profiles:

`<ComfyUI output>/VRGDG_Video_Profiles/scene_defaults/<name>.json`

Changes replace only the setting or preset components edited on the targeted scenes, including existing overrides for those components. Unselected scenes retain their settings. Generated prompts and rendered media are not regenerated by a settings edit; new generation uses the updated values. Camera-flow sequences retain original timeline indexes when applying to a subset. Empty or stale selections never fall back to all scenes.

Per-scene settings persist as `scene_defaults` on timeline segments and Storyboard cards, using the existing snake-case project default names. UI normalization, Storyboard disk saves, timeline synchronization, prompt payloads and API/MCP card edits preserve this object. Explicit zero, false and empty values are respected. The API accepts `scene_defaults` through the existing scene PATCH endpoint, validates setting names and values, and rejects project-only story arc detail there. Nonempty API objects merge setting keys; an empty object clears the record.

Undo restores the fields changed by the last operation and saves the result, while preserving unrelated scene edits. A preset is one undo transaction. Video Prep does not apply hidden Image Prep/world-style controls from a saved preset.

Implementation lives in `web/storyboard_builder/defaults_presets.mjs` (preset UI/mappings), `defaults_auto_apply.mjs` (scope/automatic application/Undo), `scene_defaults_state.mjs` and `storyboard/scene_defaults.py` (shared field contract), `builder/scene_defaults_presets.py` (atomic storage/validation), and `builder/routes.py` (thin REST handlers). These are Builder routes, outside the Agent API v1 export catalog; route contracts are recorded in `AGENT_GUIDE.md`.
