User-installed LUTs

No LUT files or preview images are bundled. The previous third-party collection
was removed because redistribution permission could not be verified.

To use your own LUTs:
1. Obtain .cube files directly from their creators under terms allowing your use.
2. Copy them into this LUTS folder.
3. Open Builder > Post Process > LUTS and click Refresh.

Optional preview images go in LUTS/examples and use the same base filename as the
LUT (for example MyLook.cube and examples/MyLook.jpg). Use images you have rights
to use. A preview is not required.

You can also create a LUT from your own color palette with the existing VRGDG
palette-to-LUT node. User-installed/generated LUTs and previews are excluded from
Git and registry packages by default. Permission to use a LUT in a video does not
necessarily permit redistributing its file in software. Do not bundle downloaded
LUTs or third-party previews without explicit redistribution permission.

Projects that selected a removed LUT must select another licensed LUT, restore a
lawfully obtained local copy, or disable that LUT before rendering. This change
does not rewrite existing project settings or remove files from Git history or
previously published packages.
